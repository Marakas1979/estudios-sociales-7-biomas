# Español · 7.º año

Material web interactivo para Español de séptimo año, III trimestre de 2026. La guía del I taller incluye texto dramático, normas de acentuación, división silábica, tilde diacrítica, comprensión de textos no literarios y un examen final imprimible de 50 puntos. La guía del II taller cubre conectores textuales, modos discursivos, repetición y redundancia, y señala que sujeto, predicado y clasificación de adjetivos deben repasarse desde las prácticas y anotaciones del cuaderno. Incluye un simulacro imprimible de 50 puntos. Las lecturas se dejan reservadas para estudio por aparte; el texto no literario para analizar se agrega en el examen.

## Publicación

El sitio está preparado para GitHub Pages desde la raíz del repositorio. `index.html` es la guía del I taller; `examen-final.html`, su examen final. `taller-ii-2026.html` es la guía del II taller y `examen-practica-taller-ii.html` su simulacro. No se requieren dependencias ni archivos externos.

## Privacidad del avance

El resumen del quiz se conserva solo en el almacenamiento local del navegador. No se envían respuestas a ningún servidor.
