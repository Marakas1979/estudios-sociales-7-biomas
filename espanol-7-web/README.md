# Español · 7.º año

Guía web interactiva para el I taller del III trimestre de 2026. Incluye texto dramático, normas de acentuación, división silábica, tilde diacrítica, comprensión de textos no literarios y un examen final imprimible de 50 puntos. Las lecturas se dejan reservadas para estudio por aparte.

## Publicación

El sitio está preparado para GitHub Pages desde la raíz del repositorio. La guía principal es `index.html`; el examen final está en `examen-final.html`. No se requieren dependencias ni archivos externos.

## Privacidad del avance

El resumen del quiz se conserva solo en el almacenamiento local del navegador. No se envían respuestas a ningún servidor.
