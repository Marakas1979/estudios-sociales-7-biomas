# Español · 7.º año

Guía web interactiva para el I taller del III trimestre de 2026. Incluye texto dramático, normas de acentuación, división silábica, tilde diacrítica y práctica de comprensión de textos no literarios. Las lecturas se dejan reservadas para estudio por aparte.

## Publicación

El sitio está preparado para GitHub Pages desde la raíz del repositorio. La página principal es `index.html` y no requiere dependencias ni archivos externos.

## Privacidad del avance

El resumen del quiz se conserva solo en el almacenamiento local del navegador. No se envían respuestas a ningún servidor.
