# Estudios Sociales 7.º · II Taller · III trimestre 2026

Guía web interactiva para repasar geografía de la producción alimentaria, consumo, acceso a alimentos, sostenibilidad del suelo y estado del hambre en el mundo.

## Contenido

- Pantallas cortas y organizadas por tema.
- Cuatro quizzes con retroalimentación inmediata, basados también en las actividades del libro.
- Registro de avance y descarga CSV.
- Simulacro escrito, listo para imprimir.
- Visor ampliable de las páginas fotografiadas 202–213 del libro.

## Privacidad del avance

El navegador conserva localmente el estado de las respuestas revisadas. No se envían respuestas a un servidor. Para compartir resultados, descarga el CSV desde la pantalla **Mi avance**.

## Sitio

La guía está publicada en GitHub Pages en una carpeta propia para conservar intacta la página principal del repositorio.

## Visor de páginas del libro

Abre `fuentes-libro.html` para consultar las fotografías originales de las páginas 202–213. El visor muestra una página por vez, permite ampliar el texto, ir directamente a otra página con los botones y mandar a imprimir la página seleccionada. Las imágenes se guardan en `fuentes-libro/` y deben permanecer junto al archivo HTML.
